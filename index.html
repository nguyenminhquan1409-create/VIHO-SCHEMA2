1. Tải File Excel Tổng Mẫu (Chuẩn Cả Giải)

2. Tải Lên File Excel Tổng Để Tự Động Phân Phối
Hệ thống tự gom VĐV cùng hạng cân, tự tạo đội cho nội dung Đồng đội và chia về đúng Sân.
